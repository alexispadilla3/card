## Digital Buisness Card
This was my first time using html and css in my Web Typorgraphy course at University of Massachusetts Dartmouth. Throughout this project I used CSS grid to aid the designing process. 

## Process
This was my process in making, I started with figma, which helped me establish the overall visual direction. The visual direction I was aiming for was clean and modern, using simples lines and shapes. The color pallete choosen, was from my portfolio to keep a consistent theme. After, making the wireframes, color and icons were added, to create the high fidelity mock-up. Then, I exported a png of the design, and added it into the document to ensure correct sizing. While this was an easy step, I had to resize and center the file, as it was to small. The file sized was doubled to esnure readability and spacial awareness. Once that was all set up, the next step I took was importing the assest, colors and fonts. After that, it was smooth sailing except challenges did arise throughout the making of it.

##Reflection
The biggest challenge was positioning the text and images, especially the 3 divider lines that break the portfolio and email text. Ensuring everything sat correctly and responsively took a lot of trial and adjustment. The easiest part was adding in the assets, lines of text, fonts, and colors. 

##Conclusion
While this project was time-consuming, I learned the CSS grid layout.Overall, this project helped me build a strong foundation in front-end development and gave me a better understanding of how design translates into code.
